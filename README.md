CelebrationHallManagementSystem

Overview

CelebrationHallManagementSystem is a web-based application designed to streamline the process of booking marriage halls for various events such as weddings, receptions, birthday parties, engagements, and exhibitions. The system offers an intuitive and professional user interface, ensuring seamless booking management for both users and administrators.

Features
User Authentication: Secure login and registration for users and admins.
Hall Booking System: Users can book halls by selecting date, time, and event type.
Admin Panel: Admins can approve or reject booking requests, set event prices, and manage hall availability.
Booking Management: Tracks booking status, user details, and approval history.
Pricing Display: Users can view hall rental prices set by the admin.
Enhanced UI: Responsive and visually appealing interface using Bootstrap for an interactive experience.
Database Integration: MongoDB (local) for efficient storage and retrieval of booking data.

Technologies Used
Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: Python
Database: MongoDB (local)
Installation & Setup

Clone the repository.
Install required dependencies.
Run the server and access the application through the browser.
